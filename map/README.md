# PUNCH ’N’ GO — интерактивная карта мира

**Страница:** https://artem-chinkov.github.io/punchngo-v3-uxflow/map/

Это самостоятельный визуальный прототип главного экрана. Основной UX-flow остаётся по адресу https://artem-chinkov.github.io/punchngo-v3-uxflow/.

## Дизайн

Единая вертикально прокручиваемая векторная карта сверху, нарисованная в авторском юмористическом фэнтези-стиле. Слегка объёмные декорации, но **без перспективной дороги, уходящей к горизонту**. Три нижние вкладки: Арсенал / Карта / Задания.

Пример первой зоны из GDD: 1-1 «Каменный завал» → 1-2 «Камни тролля» → 1-3 «Логово Бульдога». Зона 2 показана как условная ледяная локация. Названия зон, будущие сюжеты и экономика не утверждены.

## Возможности

- Прокрутка карты вверх-вниз и возврат к текущему уровню.
- Узлы завершённых, активных и заблокированных уровней.
- Кликабельные карточки миссий с NPC, целью и брифингом.
- Демонстрация необязательного накопительного поручения тролля.
- Сюжетное открытие следующего уровня / зоны без звёзд.
- Вкладки Арсенал, Карта, Задания, верхние счётчики ресурсов (условная экономика).
- Из меню настроек можно переключить демопрогресс: 1-1, 1-2, босс, следующая зона.
- Из брифинга есть переход к симулированному бою основного UX-flow и действующему боевому v2.

## Архитектура

Файлы в подпапке map: index.html, styles.css, art.js, map.js. Самостоятельный статический HTML/CSS/JS без Phaser и сборки. art.js однократно создаёт SVG-пейзаж (лес, дорога, рунические камни, замок, тролль, снежная зона); map.js отвечает за состояние и управление. Прогресс примера сохраняется в sessionStorage только текущей вкладки. Все основные файлы UX-flow находятся вне этой папки и не изменяются.

## Ограничения

Это UX-демонстрация, не полноценная боевая игра. Фэнтезийная история и экономические показатели условные, функции Кузницы и Арсенала остаются открытым вопросом. Изображение карты создано программно из собственных векторных элементов, а не нарезано из одного растрового скриншота.
