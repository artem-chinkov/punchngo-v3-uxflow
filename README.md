# PUNCH ’N’ GO — UX Flow v3

Интерактивный **UX-flow + 25 мобильных wireframe-состояний** будущей версии PUNCH ’N’ GO.

Открыть после настройки GitHub Pages: https://artem-chinkov.github.io/punchngo-v3-uxflow/

## Возможности

- Карта из 25 связанных UX-экранов; фильтры, поиск и быстрые сценарии.
- При выборе узла открываются два связанных окна: мобильный wireframe и описание экрана с переходами.
- Переходы между экранами работают также из кнопок внутри телефона.
- Симуляция обучения и забега: удары, удержание, боковые атаки, контратаки, супер-рывок, пружинный апперкот, XP и выбор одного из трёх улучшений.
- Три демонстрационных этапа первой зоны, события, ветвление на победу и поражение.
- NPC-поручения с накопительным прогрессом, без обязательных трёх звёзд.
- Концептуальные Кузница / Арсенал / экономика, помеченные отдельно от утверждённого дизайна.
- Работа без сборки, сервера, API и внешних библиотек.

## Что является прототипом

Проект **не содержит боевой движок v2**, визуальных production-ассетов и серверного сохранения. Все примеры прогрессии, ресурсов, экипировки и наград — демонстрационные, а не окончательно утверждённый баланс.

**Статусы:** `R` — уже есть как механика в v2 (wireframe — интерпретация, не копия UI); `D` — согласованное направление, ещё не реализовано; `H` — пример/гипотеза; `O` — открытое решение.

## Как запустить

Просто откройте `index.html` в современном браузере или используйте GitHub Pages.

Для GitHub Pages: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

Файлы: `index.html`, `styles.css`, `app.js`, `.nojekyll`.

## UX-модель

1. Первый запуск / обучение → карта
2. Карта → зона → этап → NPC-брифинг → подготовка → забег → событие → улучшение → босс → результат
3. Поражение: основная цель текущей попытки сбрасывается; этап можно повторить
4. Успех: открывается следующий этап; после победы над боссом — следующая зона
5. NPC-поручения, рекорды и достижения доступны отдельно, звёзды не используются
6. Экономика и различие Кузницы / Арсенала остаются открытыми решениями.

Авторинг: автономный HTML/CSS/JavaScript без зависимостей.
